# Product Requirements Documents

This directory contains PRDs for Open CIS features and capabilities.

## PRD Index

- [PRD-0001: Admin Interface](./0001-admin-interface.md) - openEHR/EHRBase management UI for templates, EHRs, compositions, and AQL queries
- [PRD-0002: Patient CRUD Operations](./0002-patient-crud.md) - Complete patient creation, update, and deletion functionality
- [PRD-0003: Encounter CRUD Operations](./0003-encounter-crud.md) - Complete encounter management for tracking patient visits and clinical interactions
- [PRD-0004: Vital Signs Chart with openEHR Transparency](./0004-vital-signs-chart.md) - Vital signs recording/charting with blood pressure and pulse, plus openEHR metadata inspection
- [PRD-0005: oehrpy SDK Integration](./0005-oehrpy-sdk-integration.md) - Python SDK for openEHR/EHRBase integration
- [PRD-0006: CAVE Form (Allergies & Adverse Reactions)](./0006-cave-form.md) - Patient allergy/intolerance recording with openEHR integration and clinical safety banners
- [PRD-0007: GitHub Pages Documentation Site](./0007-github-pages-docs.md) - Public documentation site with architecture docs, blog series, oehrpy reference, and brand kit
- [PRD-0008: Improved Error Handling](./0008-error-handling.md) - Consistent error handling across the application
- [PRD-0009: System Info View](./0009-system-info.md) - System health diagram, registered openEHR templates, version info, and data statistics
- [PRD-0010: oehrpy Coverage Gaps](./0010-oehrpy-coverage-gaps.md) - Uncovered openEHR use cases and planned SDK enhancements
- [PRD-0011: Brand Kit Integration](./0011-brand-kit-integration.md) - Integration of Open CIS brand identity into the application UI
